# Jetson 多地图建图与循线操作

**换场地时只改 `dogroute use` 后面的地图名。** 以下命令在 Jetson 的终端输入。选中的名字跨终端、跨重启保留，随时用 `dogroute status` 查看。名称区分大小写，例如已有地图是 `office4`，新场地可以叫 `plaza01` 或 `RUN1`。

## 第一次到新场地

| 顺序 | Jetson 命令 | 现场操作和完成标志 |
| --- | --- | --- |
| 1．选新地图 | `dogroute use plaza01` | 选一个新名字。建图起点最好选在容易再次找到的位置，记住狗头朝向。 |
| 2．建图 | `dogroute mapping` | 在起点站稳后运行。使用现场遥控器带狗走过要演示的路线，再回到起点、恢复原朝向。 |
| 3．保存 | `dogroute save` | 看到已保存的关键帧数和地图目录后再进行下一步。保存成功会结束建图。 |
| 4．生成二维底图 | `dogroute grid` | 将这张图的关键帧投影为 Nav2 栅格，终端打印 `nav2/map.yaml` 的位置。每张新地图做一次。 |
| 5．定位 | `dogroute locate` | 狗在建图起点、与建图时同姿态同朝向。看到“定位已匹配”后，在 RViz 对照两面固定墙或其他固定物体和机身朝向。 |
| 6．打开画线窗口 | `dogroute draw` | 使用工具栏带 **Draw Route** 的 RViz 窗口，底图显示当前地图名。 |
| 7．准备机身 | `dogroute stand` | SDK 取得控制权，进入零速 Walking，等机身站稳。若在定位前已用此命令站起，保持站稳即可。 |
| 8．画线 | 在 RViz 点 **Draw Route** | 在机身红绿坐标轴的交点按住鼠标左键，沿要求的路线拖到 B，松手。紫线是保存结果；重画会替换本图的上一条线。 |
| 9．循线 | `dogroute walk` | 机器狗从当前位置沿紫线前进。正常启动时，机身中心应在 A 周围 20 厘米内。看到“已到达 B”即完成。 |

建图时由遥控器操纵。如果上一次运行后 SDK 仍持有控制权，先结束循线并运行 `dogroute release`。雷达沿用这台机器已有的开机驱动。做定位时若狗坐着，而本图是站着建的，先恢复建图时的站姿。

## 已有地图再次使用

比如回到 Office4，把狗放在当时的建图起点，朝向一致。逐条执行：

```bash
dogroute use office4
dogroute locate
dogroute draw
dogroute stand
```

在 RViz 看底图和紫线。若从同一个 A 再走同一条线，可以直接复用。需要换路线时，用 **Draw Route** 重新画。确认后运行：

```bash
dogroute walk
```

`draw` 会检查并复用本图的栅格，首次打开时也可以自动生成。手动按 **Ctrl+C** 结束当前循线；人在原线路段附近、想接着走时可用 `dogroute walk --resume`。现场收工、循线结束后，先执行 `dogroute release` 交还控制权，再执行 `dogroute stop` 关闭画线和定位。两条命令分别负责机身和导航程序。

## 地图、路线和车辆参数在哪里

每张图独立保存在 `/home/nvidia/robot_ws/maps/<地图名>/`。

| 文件 | 用途 |
| --- | --- |
| `map.pcd` | FAST-LIO2 定位所用的三维点云。 |
| `poses.txt`、`patches/` | 本次建图的关键帧位姿和扫描，用来生成二维栅格。 |
| `nav2/map.yaml`、`nav2/map.pgm` | RViz 画线时使用的二维底图。 |
| `routes/hand_drawn.json` | 这张地图当前保存的紫线。循线时会核对地图名和点云指纹。 |

定位使用三维点云。手绘路线是 Nav2 跟踪器的输入，实时雷达负责前方障碍判定。每张地图分别保存地面高度，共用车辆尺寸、速度和停车规则。循线的公共配置在 `/home/nvidia/ws_route/src/office4_route/config/controller.yaml`，其中 `office4_route` 是软件包名，在新场地也使用同一份。

新平地地图从站姿下第一帧的位置和雷达安装高度估算地面；已有本图投影记录时复用记录。如果已经核实本图的地面高度，例如地图坐标下为 −0.46 米，可以在打开画线窗口前用 `dogroute grid --floor-z -0.46` 生成。这个数要按该场地的地图坐标填写。

如果旧 SSH 终端提示找不到 `dogroute`，可在该终端运行一次 `export PATH="$HOME/.local/bin:$PATH"`，也可以直接使用 `~/robot_tools/dogroute`。例如 `~/robot_tools/dogroute status`。
